Deskripsi
Proyek ini adalah purwarupa AI Agent untuk IT Helpdesk yang dirancang untuk memandu karyawan menyelesaikan masalah teknis secara mandiri. Antarmuka dibangun menggunakan HTML, CSS, dan JavaScript murni berdasarkan hasil instruksi terstruktur (3 Layer Prompt) kepada AI.

Fitur Utama

Panduan Step-by-Step: Alur percakapan interaktif yang menanyakan status keberhasilan perbaikan di setiap langkah.

Simulasi Chat Realistis: Dilengkapi animasi typing indicator (jeda mengetik) sebelum AI membalas pesan.

Eskalasi Terkonfirmasi: Tombol eskalasi tiket IT yang dilengkapi modal pop-up konfirmasi pencegah klik tidak disengaja.

Cara Menjalankan Proyek
Unduh repository ini dan buka file index.html langsung melalui browser.
